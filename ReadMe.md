# GhostPlando

This mod provides functionality for the **Incorporeal Echoes** plando as seen in Holloween 2026. The ICDL files for the plando can be found here:
https://github.com/TheMathGeek314/GhostPlando/tree/main/ICDL%20Files

This mod also can add content to normal rando files:
<details>
	<summary>Spoiler</summary>

	The Mimic Paragon Nosk fight can be included if selected from the connections menu.
	Though this fight should technically require wings and shade cloak, logic was not touched so that the hash should match with differing settings. 
	
	Not recommend for use with TheRealJournalRando, you won't get the Nosk journal entry.
</details>

## Required Connections
- AccessRandomizer
- Lore Randomizer
- MoreDoors

## Additional Info
<details>
	<summary>Spoiler</summary>

	The music for the Mimic Paragon Nosk boss fight is Phantom's theme from Silksong
</details>
